# Aetheris Shader

## Minecraft Cinematic Architectural Rendering Shader

Aetheris Shader is a real-time rendering project
focused on Minecraft architectural visualization.

## Vision

Create a flexible shader system that allows builders
to present different architectural styles with
cinematic lighting and atmosphere.

## Features

- Dynamic lighting
- Atmospheric rendering
- Material enhancement
- Cinematic post-processing
- Architectural presets

## Roadmap

### v0.1 Core
- Shader pipeline
- Basic lighting
- Color grading

### v0.2 Atmosphere
- Sky
- Fog
- Volumetric effects

### v1.0
- Complete architectural rendering system
